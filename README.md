# Умная система контроля уровня и расхода воды (Smart Water Tank IoT)

Учебный IoT-проект для автоматического контроля уровня воды в резервуаре, управления насосом и сбора статистики потребления воды. Проект реализуется на базе микроконтроллера ESP32 и облачной платформы ThingSpeak.

## Актуальность
Контроль за наполнением резервуаров с водой (в частных домах, на дачах или производствах) часто требует ручного вмешательства. Ручное включение/выключение насоса неудобно и несет риски: можно забыть выключить насос (вода перельется) или забыть включить (остаться без воды). 
Кроме того, пользователю важно понимать, сколько воды расходуется за день или неделю, чтобы контролировать и экономить ресурсы.

## Решение
Автономная IoT-система, которая автоматически поддерживает уровень воды в заданных пределах с помощью "умной розетки", а также собирает статистику расхода воды и отправляет её в облако для мониторинга в реальном времени.

## Функционал проекта
1. **Мониторинг текущего уровня:** Ультразвуковой датчик измеряет уровень воды в реальном времени (вычисляется в процентах или литрах).
2. **Умная автоматика (Логика Мин/Макс):** 
   * **Минимум (20%):** При критическом падении уровня воды микроконтроллер подает сигнал на включение умной розетки (в проекте имитируется светодиодом), к которой подключен насос.
   * **Максимум (90%):** Как только вода достигает верхней границы, подача питания на умную розетку прекращается.
3. **Облачная аналитика:** Данные отправляются на сервер ThingSpeak, где пользователь может отслеживать:
   * Текущий уровень воды в баке (график);
   * Объем потребленной воды (за день/неделю);
   * Статус работы насоса (включен/выключен).

## Аппаратное обеспечение
* **Микроконтроллер:** ESP32 (со встроенным Wi-Fi модулем)
* **Датчик расстояния:** Ультразвуковой дальномер HC-SR04
* **Имитация исполнительного устройства:** Светодиод (имитирует умную розетку/реле для насоса)

## Программное обеспечение и сервисы
* **Среда разработки:** Arduino IDE (C++)
* **Облачный сервис:** [ThingSpeak API](https://thingspeak.com/) — для логирования данных и визуализации графиков.

## Алгоритм работы системы
1. При включении ESP32 подключается к заданной Wi-Fi сети.
2. В основном цикле микроконтроллер считывает показания с датчика HC-SR04.
3. Расстояние переводится в процент заполненности бака.
4. Проверяются условия для управления светодиодом (насосом):
   - Если `Уровень <= 20%`, Светодиод Включается (1).
   - Если `Уровень >= 90%`, Светодиод Выключается (0).
5. Система рассчитывает расход воды (разница между прошлым и текущим уровнем при выключенном насосе).
6. Каждые `N` секунд пакет данных (Уровень воды, Статус насоса, Расход) отправляется через HTTP-запрос в каналы ThingSpeak.
