# Умная система контроля уровня и расхода воды (Smart Water Tank IoT)

Учебный IoT-проект для автоматического контроля уровня воды в резервуаре, управления насосом и сбора статистики потребления воды. Проект реализуется на базе микроконтроллера ESP8266 и облачной платформы Rightech IoT Cloud.

## Актуальность
Контроль за наполнением резервуаров с водой (в частных домах, на дачах или производствах) часто требует ручного вмешательства. Ручное включение/выключение насоса неудобно и несет риски: можно забыть выключить насос (вода перельется) или забыть включить (остаться без воды). 
Кроме того, пользователю важно понимать, сколько воды расходуется за день или неделю, чтобы контролировать и экономить ресурсы.

## Решение
Автономная IoT-система, которая автоматически поддерживает уровень воды в заданных пределах с помощью "умной розетки", позволяет удаленно настраивать параметры, а также собирает статистику расхода воды и отправляет её в облако для мониторинга в реальном времени.

## Функционал проекта
1. **Мониторинг текущего уровня:** Ультразвуковой датчик измеряет уровень воды в реальном времени (вычисляется в процентах или литрах).
2. **Умная автоматика (Логика Мин/Макс):** 
   * **Минимум (по умолчанию 20%):** При падении уровня воды микроконтроллер подает сигнал на включение умной розетки (в проекте имитируется светодиодом), к которой подключен насос.
   * **Максимум (по умолчанию 90%):** Как только вода достигает верхней границы, подача питания на умную розетку прекращается.
   * Система работает автономно: при отсутствии Wi-Fi контроль уровня продолжается по последним заданным параметрам.
3. **Удаленная настройка:** Возможность менять пороги минимального и максимального уровня воды через личный кабинет в облаке без перепрошивки платы.
4. **Облачная аналитика:** Данные отправляются на платформу Rightech IoT Cloud, где пользователь может отслеживать:
   * Текущий уровень воды в баке (график);
   * Объем потребленной воды (за день/неделю);
   * Статус работы насоса (включен/выключен).

## Аппаратное обеспечение
* **Микроконтроллер:** ESP8266 (со встроенным Wi-Fi модулем)
* **Датчик расстояния:** Ультразвуковой дальномер HC-SR04
* **Имитация исполнительного устройства:** Светодиод (имитирует умную розетку/реле для насоса)

## Программное обеспечение и сервисы
* **Среда разработки:** Arduino IDE 
* **Облачный сервис:** [Rightech IoT Cloud](https://rightech.io/ru)

## Алгоритм работы системы
1. При включении ESP8266 считывает базовые настройки порогов и подключается к Wi-Fi сети и платформе Rightech.
2. В основном цикле микроконтроллер считывает показания с датчика HC-SR04.
3. Расстояние переводится в процент заполненности бака.
4. Проверяются условия для управления светодиодом (насосом):
   - Если `Уровень <= Мин_порог`, Светодиод Включается (1).
   - Если `Уровень >= Макс_порог`, Светодиод Выключается (0).
5. Система рассчитывает расход воды (разница между прошлым и текущим уровнем при выключенном насосе).
6. Каждые `N` секунд пакет данных (Уровень воды, Статус насоса, Расход) отправляется на платформу Rightech по протоколу MQTT.
7. При получении новых значений порогов из облака ESP8266 обновляет параметры срабатывания.
